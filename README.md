# SRGroups - Customer Reviews

## Project Overview
A production-ready Customer Reviews page for SR Groups (IT Solutions & Healthcare). This application allows customers to leave reviews, rate services, and read feedback from others. The application starts empty and populates dynamically as users submit their reviews.

## Features
- **Dynamic Review Submission:** Users can submit their name, username, company, rating, and review text.
- **Zero Initial State:** The application starts with 0 reviews and a 0.0 average rating.
- **Empty State UI:** Displays a friendly message when no reviews are available.
- **Live Updates:** Average rating and total reviews count update automatically upon submission.
- **Search:** Search reviews by name, username, company, or text.
- **Filter:** Filter reviews by star rating (1 to 5).
- **Sort:** Sort reviews by Newest, Oldest, Highest Rated, or Lowest Rated.
- **Local Storage:** Reviews are saved in the browser's Local Storage and persist across page refreshes.
- **Responsive Design:** Fully responsive layout for desktop, tablet, and mobile devices.
- **Accessibility:** Includes ARIA labels and keyboard navigable elements.
